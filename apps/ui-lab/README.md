# Locator UI Lab

A live inventory of the Solid components exported by `@locator/ui`. The lab imports the package source and the shared Panda theme so visual changes appear immediately.

```bash
pnpm ui:lab
```

Open [http://127.0.0.1:3344](http://127.0.0.1:3344).

The specimens are grouped by responsibility and tagged by provenance:

- Park UI: near-upstream Park/Ark composition
- Park / local: Park recipes or Ark behavior with Locator wrappers
- Locator: product-specific composition

Use `pnpm ui:lab:build` to verify the standalone production build.
